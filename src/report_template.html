Can LLMs be confused on purpose?

How to read this page

Each test item is a pair: one Eedi question, plus one wrong option (a distractor) that Eedi tagged with a misconception. Example: for 1/2 + 1/3, the distractor 2/5 is tagged "adds numerators and adds denominators".

We ask each model the question three ways:

  • Matched persona: "You are a student who believes [that misconception]". Picking the tagged distractor is a hit.
  • Control persona: the same question, but the student believes an unrelated misconception. A hit here means the distractor is just tempting.
  • No persona: just answer. This checks whether the model can solve the question at all.

Lift = matched hit rate − control hit rate. This is the headline number: how much the specific misconception steers the answer. Each persona call uses one of two framings: student ("you are a student who…") or teacher ("a student believes…; predict their pick").

Method & caveats

  • Data: Eedi "Mining Misconceptions in Mathematics" (Kaggle, CC BY-NC 4.0, non-commercial). Image-based questions are excluded. This page contains competition data and is for local viewing only.
  • Eedi's misconception tags are treated as ground truth. Some are noisy, which caps the achievable hit rate.
  • Options are shuffled for every call (seeded). The tagged distractor's position is balanced across A–D, and matched and control calls for a pair use the same option order, so position bias cancels out of the lift.
  • Single calls only. Replies are constrained to {"answer": "A|B|C|D"}, the same method for every model. Temperature is 0 where supported; gpt-5-mini runs at minimal reasoning effort.
  • LLM personas are not real students. Nothing here is validated against real student response rates.
